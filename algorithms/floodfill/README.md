# Floodfill pygame
A simple floodfill algorithm made with PyGame.

## Keybinds
| Key | Function | Event |
| 1 | Floodfill with blue | Single press |
| 2 | Floodfill with red | Single press |
| 3 | Floodfill with green | Single press |
| s | Save canvas to PNG image | Single press |
| e | Eraser tool | Holding key |

---

## Features
[x] Floodfill with colors
[ ] Paint with colors, not only black.
[x] Eraser tool
[x] Save canvas to PNG image
[ ] Undo/Redo functionality
[ ] Circle maker (key C) with adjustable radius (popup)
